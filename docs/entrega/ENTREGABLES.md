## Limitaciones que conviene decir en la sustentación

- **Despliegue público:** el Dokploy compartido del diplomado no quedó disponible para el equipo. La demo corre en el Mac del líder con las mismas imágenes firmadas (y una URL pública temporal con `--tunel` si hace falta), y la evidencia de GitOps (Argo CD, Kyverno, Sealed Secrets, SLO) se genera de punta a punta en GitHub Actions con kind en cada PR.
- **Hardware:** equipos de 8 GB. Los modelos son pequeños (3B) y el clúster es de un nodo: no se prueba alta disponibilidad real.
- **Datos:** todas las métricas de IA salen de datos sintéticos escritos por el equipo; hace falta un piloto con estudiantes reales.
